# Wrap-up & Going Further

## What this module covered

| Piece | What it does |
|---|---|
| `define_deep_agent(...)` | The managed counterpart to `create_deep_agent(...)` |
| `agent.py` | Defines the agent, its model, and its tools |
| `instructions.md` | The system prompt, editable live in Context Hub |
| `sandbox/__init__.py`, `sandbox/setup.sh` | Declares and provisions an isolated, per-thread sandbox |
| `skills/` | On-demand playbooks, also editable live in Context Hub |
| `identity.py` | Declares who's allowed to call the deployment |
| `channels/slack.py` | Puts the agent in Slack, with MDA provisioning the app itself |

MDA keeps the agent-building primitives you already know from this course (a model, a system prompt, tools, and sandboxed code execution) and replaces the infrastructure around them (a sandbox provider, a deploy pipeline, a way to iterate on prompts without redeploying, your own Slack app) with a handful of declarations and a managed runtime.

## Go further

This module was a conceptual tour of what Managed Deep Agents adds on top of the deep agents you've already been building: enough to know what it is and when to reach for it, but not a hands-on build. For that (deploying a project yourself, editing Context Hub live, and wiring up Slack end to end), continue with the dedicated **Managed Deep Agents** course.
