# Wrap-up & Going Further

## What this module covered

| Piece | What it does |
|---|---|
| `define_deep_agent(...)` | The managed counterpart to `create_deep_agent(...)` |
| `agent.py` | Defines the agent, its model, and its tools |
| `instructions.md` | The system prompt, editable live in Context Hub |
| `sandbox/__init__.py`, `sandbox/setup.sh` | Declares and provisions an isolated, per-thread sandbox |
| `skills/` | On-demand playbooks, also editable live in Context Hub |
| `identity.py` | Declares who's allowed to call the deployment |
| `channels/slack.py` | Puts the agent in Slack, with MDA provisioning the app itself |

The throughline across all of it: MDA gives you the same agent-building primitives you already know from this course (a model, a system prompt, tools, and sandboxed code execution) and replaces the infrastructure you'd otherwise stand up yourself (a sandbox provider, a deploy pipeline, a way to iterate on prompts without redeploying, a Slack app of your own) with a handful of declarations and a managed runtime underneath them.

## Go further

This module was a fast, conceptual tour of what Managed Deep Agents adds on top of the deep agents you've already been building. It's enough to know what it is and when you'd reach for it, not a full hands-on build. For the hands-on version (deploying a project yourself, editing Context Hub live, and wiring up Slack end to end), continue with the dedicated **Managed Deep Agents** course.
